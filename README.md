# 3D 2048

2048 on a 3×3×3 (or 4×4×4) cube. Single-file HTML/canvas game, built for mobile and desktop.

**Touch:** one-finger swipe moves along the axis you swipe toward (see the X/Y/Z gizmo); two-finger drag rotates the view.
**Keyboard:** W/S up/down, A/D left/right, E/Q away/toward; hold Z + W/A/S/D to rotate; arrow keys also work.
Unlimited undo, 3×3×3 / 4×4×4 toggle.

Open `index.html` in a browser.
